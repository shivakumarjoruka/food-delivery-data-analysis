# Food Delivery Data Analysis

## 📌 Overview
This project analyzes a food delivery dataset using **Python** and **Pandas** to uncover insights related to customer behavior, restaurant efficiency, and revenue trends.  
The analysis is structured to answer analytical questions commonly found in data analytics coursework and practical examinations.

Multiple datasets containing **orders, users, and restaurant information** are merged into a unified dataset to ensure accurate and meaningful analysis.

---

## 📊 Objectives
- Understand customer ordering behavior
- Evaluate restaurant performance
- Analyze revenue patterns
- Practice real-world data manipulation and analysis techniques
- Answer conceptual, numerical, and multiple-choice analytical questions

---

## 🗂️ Dataset Description
The project uses multiple datasets that include:
- **Order details** (order ID, amount, timestamps, etc.)
- **User information** (customer-related data)
- **Restaurant data** (restaurant details and performance metrics)

All datasets are merged using appropriate keys to maintain data integrity.

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- Google Colab Notebook

---

## 🔍 Analysis Workflow
1. Import required Python libraries
2. Load and inspect datasets
3. Clean and preprocess data
4. Merge datasets into a single structure
5. Perform exploratory data analysis (EDA)
6. Answer analytical questions using dynamic computations  
   *(no hard-coded values used)*
